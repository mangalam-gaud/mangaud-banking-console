# MANGAUD BANKING CONSOLE - COMPREHENSIVE PROJECT DESCRIPTION

## PROJECT NAME
Mangaud Banking Console

## PROJECT AIM
To build a comprehensive, full-featured banking console that demonstrates production-ready software engineering patterns, role-based access control, and a complete MERN stack architecture. The console provides a complete banking user experience for six distinct user roles: Customer, Teller, Loan Officer, Branch Manager, Auditor, and Administrator. It serves as both a functional demo product and a reference architecture for building secure fintech applications with React + Express + MongoDB.

## PROJECT SUMMARY
Mangaud Banking Console is a full-stack MERN (MongoDB, Express.js, React 18, Node.js) web application that delivers a complete banking experience for six distinct user roles: Customer, Teller, Loan Officer, Branch Manager, Auditor, and Administrator. The console demonstrates production-ready patterns including JWT authentication, granular role-based access control (RBAC) with 62 distinct permissions, optimistic UI updates with automatic rollback, a robust audit logging system, scheduled jobs for deposits and standing instructions, and comprehensive test coverage (72 unit/integration tests + 9 E2E tests).

The frontend follows React 18 + TypeScript with Tailwind CSS for styling, Zustand for state management, and Playwright for end-to-end testing. The backend uses Express.js with TypeScript, Mongoose for MongoDB ODM, JWT for authentication, and Zod for input validation. All mutations run through optimistic UI with rollback, and a comprehensive audit log captures every change.

## KEY FEATURES

### Authentication & Authorization
- JWT-based authentication (access token 15min, refresh token 7 days)
- httpOnly cookie fallback for refresh token
- Role-based access control with 6 roles and 62 fine-grained permissions
- Branch-scoped access for teller/manager roles (SOL-id style)
- Ownership checks on all resources (own/any pattern)

### Banking Features
- **Accounts**: Open, close, deposit, withdraw, transfer, interest calculation
- **Cards**: Issue, freeze/unfreeze, cancel, limits, PIN set, nickname, reveal CVV
- **Loans**: Apply, repay (from any own account), calculate interest, staff queue (manager/loan officer approve, disburse via admin)
- **Deposits (FD)**: Open, close, premature closure with penalty, auto-maturity scheduler
- **Payments**: Internal transfer, IMPS/NEFT/RTGS, beneficiary management
- **Standing Instructions**: Create, pause, resume, run now, cancel, monthly load summary
- **Statements**: Generate PDF statements per account
- **Transactions**: Full transaction history with filtering, pagination, search
- **Notifications**: Real-time list, mark read/all, clear read, delete, unread badge count
- **Beneficiaries**: CRUD, favourite toggle, search, optimistic updates
- **Standing Instructions**: Create, pause, resume, run now, cancel, monthly load summary
- **KYC**: Submit documents, staff review queue, approval workflow
- **Audit Log**: Immutable trail of every mutation, branch-scoped for staff
- **Admin**: User management, branch structure, system config

### UI/UX
- Optimistic UI with automatic rollback on all mutations
- Role-specific dashboards (6 distinct dashboard views)
- Responsive design (mobile + desktop)
- Dark mode support
- Skeleton loading states
- Toast notifications for all actions
- Empty states for all data-empty scenarios
- Form validation with Zod (client + server)

## SECURITY

- **Helmet**: Security headers (CSP, HSTS, X-Frame-Options, etc.)
- **CORS**: Strict origin allowlist
- **Rate limiting**: 6000 requests/15min general, 50 requests/15min auth endpoints
- **JWT**: Short-lived access (15min), longer refresh (7 days), httpOnly cookies
- **bcrypt**: Password hashing with 12 rounds
- **Audit**: Every mutation logged with actor, action, entity, metadata
- **Branch scoping**: Staff can only access their branch
- **Validation**: Zod schemas on every mutation endpoint
- **SQL injection prevention**: Mongoose ODM (parameterized queries)
- **XSS protection**: React escapes by default, Content-Security-Policy

## KNOWN LIMITATIONS (DELIBERATE)

- No 2FA/OTP on login or money moves
- No maker-checker on payments/deposits/withdrawals (only loan approve/disburse split)
- No real KYC document verification (text input only)
- No email/SMS/push notification channel
- Statements are JSON/text, not PDF
- No password reset flow
- No account lockout after failed logins
- No session management UI
- React Router v6 has a moderate open-redirect advisory (fix requires v7 major bump)
